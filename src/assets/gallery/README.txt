Gallery images: drop .jpg / .jpeg / .png / .webp files here and rebuild (or restart npm run dev).
They appear on /gallery automatically.
To group them, put them in a sub-folder: src/assets/gallery/events/, src/assets/gallery/gaushala/, src/assets/gallery/team/ ...
The folder name becomes the filter label. Files directly in this folder go under "All photos" only.
Tip: resize to about 1600px wide before adding (keeps the site fast).
